平時也可以安排一些和剪刀能力相關的前置活動，幫助孩子的手更穩、眼睛更會帶動雙手。例如：
1. **夾夾樂**：用夾子夾棉球、積木或小紙片，練習手指力量與手眼協調。  
2. **撕貼遊戲**：撕彩紙貼在圖案上，訓練雙手合作與手部控制。  
3. **穿線或串珠**：讓孩子把大珠子、吸管片穿到繩子上，培養視覺定位與雙側協調。
